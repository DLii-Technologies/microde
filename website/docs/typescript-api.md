# `@microde/microservice`

The API reference is generated from the public TypeScript exports and their TSDoc comments.

- [`MicrodeApplication`](./api-reference/classes/MicrodeApplication.md) coordinates installed modules.
- [`MicrodeContext`](./api-reference/interfaces/MicrodeContext.md) defines the non-blocking `requestStop()` and `panic()` operations available to modules.
- [`MicrodeStopRequest`](./api-reference/interfaces/MicrodeStopRequest.md) describes an orderly shutdown request.
- [`ModuleKind`](./api-reference/enumerations/ModuleKind.md) identifies passive and active module behavior.
- [`MicrodeApplicationState`](./api-reference/enumerations/MicrodeApplicationState.md) describes the observable lifecycle state.
- [`MicrodeExecutionResult`](./api-reference/interfaces/MicrodeExecutionResult.md) reports the final outcome.
- [`MicrodeModule`](./api-reference/classes/MicrodeModule.md) defines the shared lifecycle and declares passive or active behavior.
- `ModuleHandle` and `ModuleInstanceId` identify exact named installations without exposing module objects.
- `port`, `provide`, `dependency`, and `reference` declare provider contracts and relationship slots.
- `SetupContext` resolves dependencies; `RunContext` resolves dependencies and references.
- `MicrodeApplication.install(name, factory)` returns a stable opaque handle, and
  `MicrodeApplication.bind(consumer, slotName, provider)` targets one exact installed
  instance.

These linked pages are regenerated by `pnpm docs:api` and are intentionally not committed to Git.
