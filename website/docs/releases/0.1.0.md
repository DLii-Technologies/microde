# 0.1.0

`0.1.0` is the planned initial public release of Microde's application lifecycle package.

## Included

- Composition through synchronous module factories
- Passive modules for finite work
- Active modules with orderly stop requests
- Ordered initialization and setup
- Reverse-order teardown, shutdown, and cleanup
- Observable lifecycle state
- Structured execution results with prioritized failures
- Immediate panic behavior for unrecoverable process failures

## Stability note

This is an initial `0.x` release. Validate lifecycle and shutdown behavior against your service requirements before production adoption.
